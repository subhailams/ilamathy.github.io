## Problem
Redundant questions on Q&A platforms hinder efficient knowledge retrieval. Users waste time searching through similar questions with scattered answers.

## Solution
Used ML models and text embeddings to detect and merge duplicate questions. The system identifies semantically similar questions even when worded differently.

## Key Features
- **Semantic Similarity**: BERT and Sentence Transformers for embeddings
- **ML Classification**: Multiple models for duplicate detection
- **Feature Engineering**: Question pair features for improved accuracy
- **Efficient Matching**: Scalable similarity search

## Technical Implementation
- **Tech Stack**: Natural Language Processing, Python, Scikit-learn, Semantic Similarity
- **Models**: Logistic Regression, Random Forest, XGBoost, Neural Networks
- **Embeddings**: BERT, Universal Sentence Encoder
- **Evaluation**: Precision, Recall, F1-score on Quora dataset

## Results
- High accuracy in detecting semantic duplicates
- Reduced false positives through ensemble methods
- Scalable to large question databases
